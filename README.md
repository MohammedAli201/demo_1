# React Native To-do Exercise

A small Expo application with an editable in-memory to-do list.

## Features

Add, edit and remove list entries. `App.js` contains the exercise and its styles.

## Run

```bash
npm ci
npm start
```

Use a development client or emulator compatible with the Expo SDK recorded in `package.json` (SDK 51). The latest Expo Go client may not support this historical SDK.

## Status

Learning project. Entries are held in component state and reset when the app restarts. The profile shown in the UI is sample content.
